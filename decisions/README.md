# Decision Records

> **Purpose:** Preserve the reasoning behind consequential Pravaah choices.
>
> **Pravaah OS:** v1.0.0  
> **Last Updated:** 2026-08-08  
> **Owner:** Founders  
> **Related Documents:** [Decision-making Principle](../company/principles/decision-making.md), [Changelog](../changelog/CHANGELOG.md), [Rejected Ideas](rejected-ideas.md)  
> **Estimated Reading Time:** 3 minutes

An Architecture Decision Record (ADR) captures a choice whose consequences will outlast the immediate task. It prevents institutional memory from depending on a person’s recollection.

Each ADR includes: context, decision, alternatives considered, reasoning, consequences, owner, status, and a future review date. ADRs are immutable historical records. If a decision changes, create a new ADR that supersedes it.
