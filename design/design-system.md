# Design System

> **Purpose:** Define the reusable design decisions that create coherent, accessible experiences.

## Direction

Pravaah uses an editorial-architectural expression: restrained typography, generous whitespace, neutral tones, precise composition, and useful writing. The system should feel like a well-designed book or a considered studio, not a software template.

## Typography

Type creates the primary hierarchy because language carries the business message. Choose a highly legible text face and an expressive but restrained display face only when it improves distinction. Use a small scale with clear contrast rather than many sizes.

## Spacing and layout

Use a consistent spacing scale and generous outer margins. Space establishes rhythm and gives important content room to be understood. Layout should be responsive, content-led, and resilient to longer real-world copy.

## Colour

Begin with an architectural neutral base and limited functional accents. Colour must preserve accessible contrast and should signal hierarchy or state, not novelty.

## Components

Components are reusable behaviors, not a collection of decorative cards. Define purpose, states, content rules, accessibility, and responsive behavior before styling. A moderate corner radius is preferred where needed because it feels confident rather than playful.

## Imagery and iconography

Use original, commissioned, or purposefully selected imagery. Avoid generic stock photography, robots, and visual metaphors that obscure the actual business. Icons clarify an action or concept; they do not decorate empty space.

## Illustration

Use illustration only when a real concept needs explanation and photography or language would be less clear. Keep it restrained, human, and aligned with the underlying grid.
