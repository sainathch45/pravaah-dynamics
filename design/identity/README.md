# Pravaah Visual Identity

> **Purpose:** Define the complete visual language Pravaah will use across Product 001 and every future expression.
>
> **Pravaah OS:** v1.0.0  
> **Last Updated:** 2026-08-08  
> **Owner:** Founders  
> **Related Documents:** [Brand Architecture](../../company/brand-architecture.md), [Product 001 Design Specification](../../website/design/README.md), [Design System](../design-system.md)  
> **Estimated Reading Time:** 10 minutes

Layer 3 gives Pravaah a coherent visual language before engineering begins. It creates a system, not a costume: every expression should share the same DNA without looking copied from the last one.

## Scope

This layer defines identity direction, wordmark rules, icon philosophy, colour meaning, photography, illustration, texture, motion identity, application principles, and the logo decision. It deliberately does not generate logo files, icons, photography, social images, or any website code. Those are produced only after the founders approve the chosen direction.

## Chosen direction

The recommended direction is **The Measured Wordmark**: a typography-led identity with a quiet editorial wordmark, a fine flow line as a secondary device, and no standalone symbol at launch. It is selected because it is most aligned with clarity, longevity, and the current truth boundary.

## Identity test

Before an asset or application is approved, ask: Does it make Pravaah feel more clear, considered, and dependable? Would it still feel appropriate in five years? Does it help a person understand something, or is it asking to be noticed for its own sake?
