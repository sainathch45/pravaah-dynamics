# UI and UX Practice

> **Purpose:** Connect user experience decisions to the visual interface that expresses them.
>
> **Pravaah OS:** v1.0.0  
> **Last Updated:** 2026-08-08  
> **Owner:** Founders  
> **Related Documents:** [Design Principles](principles.md), [Design Reviews](design-reviews.md), [Accessibility](accessibility.md)  
> **Estimated Reading Time:** 4 minutes

UX begins by understanding a person’s goal, context, and uncertainty. UI gives that understanding a visible, interactive form. Separating them helps Pravaah avoid treating attractive screens as proof of a useful experience.

Map the journey, decision points, constraints, edge cases, and error recovery before polishing visual detail. Write interface language that helps someone decide or act. Validate with representative users or stakeholders when the risk warrants it. Use design review to test whether an interface reduces confusion rather than merely following convention.
