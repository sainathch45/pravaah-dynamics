# Document Standard

> **Purpose:** Make every Pravaah OS document easy to trust, navigate, and maintain.
>
> **Pravaah OS:** v1.0.0  
> **Last Updated:** 2026-08-08  
> **Owner:** Founders  
> **Related Documents:** [How to Use This Handbook](../handbook/how-to-use-this-handbook.md), [Changelog](../changelog/CHANGELOG.md)  
> **Estimated Reading Time:** 3 minutes

Every Markdown document begins with a title and a metadata block containing purpose, Pravaah OS version, last updated date, owner, related documents, and estimated reading time.

The body explains why the document exists before prescribing what to do. Use short headings, concrete language, internal links where a reader needs context, and factual claims only. Update the version and changelog when the change affects the operating system rather than correcting a typo.
