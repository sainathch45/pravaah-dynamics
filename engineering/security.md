# Security Practice

> **Purpose:** Make security a normal part of responsible engineering.
>
> **Pravaah OS:** v1.0.0  
> **Last Updated:** 2026-08-08  
> **Owner:** Technology Lead  
> **Related Documents:** [Engineering Standards](standards.md), [Deployment](deployment.md), [Legal Review](../legal/legal-review.md)  
> **Estimated Reading Time:** 3 minutes

Security protects users, clients, and the company’s credibility. Identify what data exists, who can access it, how it moves, and what happens if it is exposed or unavailable. Minimise collection and access before adding controls.

Use managed secrets, least-privilege access, dependency review, input validation, safe authentication patterns, and a documented response owner. Escalate suspected exposure or misuse immediately; speed and honesty reduce harm more than concealment.
