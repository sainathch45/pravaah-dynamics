# The Pravaah Handbook

> **Purpose:** The first place every Pravaah team member learns how the company works.
>
> **Pravaah OS:** v1.0.0  
> **Last Updated:** 2026-08-07  
> **Owner:** Founders  
> **Related Documents:** [The Pravaah Way](the-pravaah-way.md), [Company Principles](../company/principles/README.md), [How to use this handbook](how-to-use-this-handbook.md)  
> **Estimated Reading Time:** 5 minutes

This handbook is a practical expression of Pravaah’s values. It is not a static rulebook. It gives people enough context to make good decisions when a founder is not in the room.

## Read in this order

1. [The Pravaah Way](the-pravaah-way.md)
2. [How to use this handbook](how-to-use-this-handbook.md)
3. [Company principles](../company/principles/README.md)
4. [Working together](working-together.md)
5. The playbook for the work you are about to do

## What we expect

Bring judgment, not just output. Ask when context is missing. Explain the reason behind a recommendation. Improve the system when you find a better way, then document the change.
