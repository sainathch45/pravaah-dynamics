> **Estimated Reading Time:** 3 minutes

## Read for context, use for action

The handbook is not homework. Read the relevant principle before a decision and the relevant playbook before a repeated activity. This prevents people from recreating standards through memory or habit.

## Improve it responsibly

If guidance is unclear, first ask whether the issue is a missing principle, a missing example, or a situation that needs a new decision. Small clarifications can be proposed in the relevant document. A material change needs an ADR, founder review, and a changelog entry.

## Document quality

Every document uses the standard header so readers know its purpose, owner, currency, dependencies, and likely reading time. Every rule should explain its reason. When the reason no longer holds, revisit the rule.

## Ownership

The founders own v1.0.0. The person closest to a practice proposes improvements; the accountable owner approves them. No one should quietly change a principle that affects other teams.
