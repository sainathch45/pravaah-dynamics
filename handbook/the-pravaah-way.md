# The Pravaah Way

> **Purpose:** A short cultural north star for every person working with Pravaah.
>
> **Pravaah OS:** v1.0.0

> **Owner:** Founders

We think before we build.

We ask before we assume.

We simplify before we optimize.

We care before we deliver.

We make technology feel quiet.

We respect attention.

We measure success by trust.

We leave every project better than we found it.

We build momentum that lasts.
