## Asset principles

Assets should support the story already approved in design. If an asset does not add clarity, trust, or usability, it should not be added.

## Asset types

- Brand and interface images approved for launch.
- Static icons and structural symbols.
- Social and sharing imagery when the canonical domain is known.
- Lightweight background or texture assets only if they remain performance-safe.

## Organisation

- Keep source assets in a predictable folder structure.
- Use descriptive filenames that reflect purpose rather than marketing language.
- Separate source files from production assets where the workflow requires it.
- Keep alt text and metadata near the asset usage, not trapped inside a design file.

## Media policy

- Do not introduce video unless the design and performance budgets justify it.
- Use next-generation image formats where supported.
- Ensure every non-decorative image has a purpose and a correct text alternative.
