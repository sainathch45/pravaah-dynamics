# Maintenance and Updates

> **Purpose:** Define how the site should be maintained after launch so it remains accurate and safe to evolve.
>
> **Pravaah OS:** v1.0.0
> **Last Updated:** 2026-08-08
> **Owner:** Technology Lead

> **Estimated Reading Time:** 7 minutes

## Maintenance model

The site should be treated as a living public product with light editorial and technical upkeep. Maintenance should cover content correction, dependency updates, accessibility checks, security review, and monitoring of inquiry quality.

## Update policy

- Small, safe fixes should be easy to release.
- Dependency updates should be routine and reviewed.
- Content should be corrected when facts change.
- Design or architecture changes that alter the system should be documented.

## Ownership

A clear owner should be responsible for keeping the public experience accurate and functional after launch.
